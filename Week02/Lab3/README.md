# Lab 3 — Arrays

Three exercises covering array creation, manipulation, and rendering with array methods like `sort`, `filter`, `reverse`, and `join`.

| # | File | Description |
|---|------|-------------|
| 1 | [01-find-duplicates-in-array.html](./01-find-duplicates-in-array.html) | Takes a comma-separated list of numbers and detects duplicate values, reporting their positions. |
| 2 | [02-array-operations-menu.html](./02-array-operations-menu.html) | Builds an array from user input, then offers a menu to sort (asc/desc), reverse, filter evens, filter divisibles, apply a discount filter, or join with a custom separator. |
| 3 | [03-product-inventory-table.html](./03-product-inventory-table.html) | Collects product data (name, quantity, price) into an array of objects and renders it as an HTML table with a total inventory value. |

## Concepts Practiced

- Array creation and iteration
- `map()`, `filter()`, `sort()`, `reverse()`, `join()`
- Array of objects
- Nested loops for duplicate detection
- Input validation loops
