# Lab 2 — Conditionals, Switch & Loops

Nine exercises covering conditional logic, switch statements, loops, string comparison, and validation.

| # | File | Description |
|---|------|-------------|
| 1 | [01-age-validation.html](./01-age-validation.html) | Validates a user's age input and shows a different message based on age group (under 13, teen, adult). |
| 2 | [02-membership-discount.html](./02-membership-discount.html) | Applies a discount to a product price depending on whether the user is a member. |
| 3 | [03-favorite-color-switch.html](./03-favorite-color-switch.html) | Uses a `switch` statement to respond to the user's favorite color. |
| 4 | [04-login-validation.html](./04-login-validation.html) | Simple login form validation with hardcoded admin credentials. |
| 5 | [05-equality-loose-vs-strict.html](./05-equality-loose-vs-strict.html) | Demonstrates the difference between `==` (loose equality) and `===` (strict equality). |
| 6 | [06-password-strength-checker.html](./06-password-strength-checker.html) | Checks if a password is "strong" based on length, digits, and uppercase letters. |
| 7 | [07-even-numbers-table.html](./07-even-numbers-table.html) | Dynamically builds an HTML table of even numbers from 1 to 30 using `document.write`. |
| 8 | [08-do-while-username.html](./08-do-while-username.html) | Uses a `do...while` loop to keep prompting until a valid (non-empty) username is entered. |
| 9 | [09-quiz-game.html](./09-quiz-game.html) | A short trivia quiz with a score tracker and a retry option using `do...while`. |

## Concepts Practiced

- `if` / `else if` / `else` chains
- `switch` statements
- Loose (`==`) vs strict (`===`) equality
- `for`, `while`, and `do...while` loops
- Input validation and type checking
- Dynamic DOM writing with `document.write()`
