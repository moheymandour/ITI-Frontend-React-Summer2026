# Lab 1 — JavaScript Fundamentals

Five exercises covering variables, type checking, conditionals, loops, and number formatting using vanilla JavaScript.

| # | File | Description |
|---|------|-------------|
| 1 | [01-sum-two-numbers.html](./01-sum-two-numbers.html) | Prompts the user for two numbers, validates they're valid numbers, and logs their sum. |
| 2 | [02-compare-two-numbers.html](./02-compare-two-numbers.html) | Prompts for two numbers, validates them, then compares which is greater, smaller, or equal. |
| 3 | [03-number-locale-formatting.html](./03-number-locale-formatting.html) | Takes a number and formats it using `toLocaleString()` in US, Arabic (Egypt), Indian, and German locales. |
| 4 | [04-dynamic-headings-loop.html](./04-dynamic-headings-loop.html) | Prompts for a message and dynamically writes it as `<h1>` through `<h6>` headings using a `for` loop. |
| 5 | [05-sum-until-100-while-loop.html](./05-sum-until-100-while-loop.html) | Uses a `while` loop to keep summing user-entered numbers until the total exceeds 100 or the user enters 0, with input validation. |

## Concepts Practiced

- `prompt()` / `alert()` for user I/O
- Type conversion with `Number()` and `isNaN()`
- Conditional logic (`if` / `else if` / `else`)
- `for` and `while` loops
- `Number.prototype.toLocaleString()` for locale-based formatting
- Dynamic DOM writing with `document.write()`
