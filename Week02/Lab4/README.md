# Lab 4 — DOM Manipulation & Interactive UI

Three interactive mini-projects using DOM manipulation, event listeners, and dynamic styling.

| # | File | Description |
|---|------|-------------|
| 1 | [01-todo-list-organizer.html](./01-todo-list-organizer.html) | A to-do list app: add tasks, mark them done (strikethrough), and delete with confirmation. |
| 2 | [02-slide-show-game.html](./02-slide-show-game.html) | An image slideshow with next/previous buttons cycling through a set of images. |
| 3 | [03-profile-card-editor.html](./03-profile-card-editor.html) | An editable profile card: change the display name, randomize the background color, and add hobbies to a list. Uses `myAvatar.png` as the profile picture. |

## Concepts Practiced

- `document.createElement()` / `appendChild()` / `removeChild()`
- Event listeners (`click`, `input`, `keypress`, `change`)
- Dynamic class toggling (`classList.toggle`)
- `confirm()` for destructive actions
- Randomization with `Math.random()`

## Notes

- `03-profile-card-editor.html` requires `myAvatar.png` to be in the same folder to display the profile picture correctly.
