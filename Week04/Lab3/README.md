# Lab 3 — Media Player & Portfolio Projects

Three larger projects: a custom video player and two personal portfolio page designs.

| # | File | Description |
|---|------|-------------|
| 1 | [01-modern-video-player.html](./01-modern-video-player.html) | A fully custom HTML5 video player with play/pause/stop/mute/loop/fullscreen controls, playback speed options, a synced progress bar, volume slider, and adjustable player size. |
| 2 | [02-personal-portfolio-bootstrap.html](./02-personal-portfolio-bootstrap.html) | A personal portfolio site built with Bootstrap 5 and Font Awesome — hero section, about, skills progress bars, projects showcase, and contact info. |
| 3 | [03-personal-portfolio-custom.html](./03-personal-portfolio-custom.html) | An alternative portfolio design built with custom CSS (no framework) — nav, intro, about, experience timeline, and a WhatsApp contact button. |

## Concepts Practiced

- HTML5 `<video>` API (`play`, `pause`, `currentTime`, `playbackRate`, `volume`, `requestFullscreen`)
- Syncing a range input with video progress via the `timeupdate` event
- Bootstrap layout, Font Awesome icons, progress bars
- Custom CSS layout with Flexbox for a framework-free portfolio design
