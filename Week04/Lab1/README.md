# Lab 1 — CSS Animations & Interactions

Three exercises covering CSS keyframe animations, transitions, and the native HTML5 Drag & Drop API.

| # | File | Description |
|---|------|-------------|
| 1 | [01-keyframe-animation.html](./01-keyframe-animation.html) | A box that cycles through colors and positions using `@keyframes`, with Start/Stop/Pause controls via `animationPlayState`. |
| 2 | [02-transition-animation.html](./02-transition-animation.html) | A box that animates color and alignment changes using CSS `transition` combined with async/await JS timing. |
| 3 | [03-drag-and-drop-gallery.html](./03-drag-and-drop-gallery.html) | A drag-and-drop image gallery using the native Drag & Drop API (`dragstart`, `drop`, `dragover`, etc). |

## Concepts Practiced

- `@keyframes` and `animation-play-state`
- CSS `transition` on multiple properties
- `async`/`await` with `setTimeout` for sequenced animations
- HTML5 Drag & Drop API (`dataTransfer`, `dragenter`, `dragover`, `drop`)
