# Lab 2 — CSS Grid & Bootstrap Pages

Five full-page projects covering CSS Grid layouts and Bootstrap 5 components.

| # | File | Description |
|---|------|-------------|
| 1 | [01-ink-portfolio-grid.html](./01-ink-portfolio-grid.html) | A responsive creative-agency portfolio grid built with CSS Grid, including a footer and Flickr-style photo strip. |
| 2 | [02-antonio-gaudi-bootstrap.html](./02-antonio-gaudi-bootstrap.html) | A Bootstrap 5 showcase page about Antonio Gaudí's architecture, using cards, flex utilities, and responsive columns. |
| 3 | [03-bootstrap-signin-form.html](./03-bootstrap-signin-form.html) | A centered Bootstrap sign-in form with email, password, and "remember me" fields. |
| 4 | [04-bootstrap-pricing-page.html](./04-bootstrap-pricing-page.html) | A Bootstrap pricing page with plan cards and a feature comparison table. |
| 5 | [05-iti-locations-page.html](./05-iti-locations-page.html) | A custom-styled landing page listing ITI's branches across Egypt, with interactive location buttons. |

## Concepts Practiced

- CSS Grid (`grid-template-areas`, `grid-template-columns`)
- Bootstrap 5 grid system, cards, forms, and navbar components
- Responsive design with media queries
- Custom SVG icons and interactive button states
