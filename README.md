### Week 3 - ITI JavaScript Training

A collection of hands-on JavaScript exercises covering array methods, function arguments, scope, closures, and asynchronous API calls with the Fetch API.

## 📁 Contents

| File | Description |
|---|---|
| `array-methods-and-function-arguments.html` | Sorting, filtering, and reducing arrays (`sort`, `filter`, `reduce`), plus a dynamic `operations()` function built with the `arguments` object, and an object with a method (`printData`) that reads user input via `prompt()`. |
| `spread-rest-and-this-keyword.html` | Finding min/max with the spread operator, a calculator function using **rest parameters**, and a comparison of the `this` keyword's behavior inside global functions, regular methods, and arrow functions. |
| `arguments-vs-rest-parameters.html` | A focused comparison between the classic `arguments` object, converting it with `Array.from()` / spread, true **rest parameters**, and why `arguments` is undefined inside arrow functions. |
| `closures-example.html` | A minimal example demonstrating **JavaScript closures** — an inner function retaining access to its outer function's scope. |
| `users-list-fetch-api.html` | A mini web app that fetches users from a public API (`jsonplaceholder`) and renders them as styled cards on the page using `async/await` and DOM manipulation. |
| `post-and-author-info-viewer.html` | A small app where the user enters a Post ID, and the app fetches the post plus its author's info from the API, with loading/error states and styled UI. Uses `post-icon.png`. |
| `post-icon.png` | Icon used by `post-and-author-info-viewer.html`. |

## 🧠 Topics Covered
- Array methods: `sort`, `filter`, `reduce`, spread operator
- `arguments` object vs. **rest parameters** (`...args`)
- The `this` keyword in different function contexts (global, regular, arrow)
- **Closures** and lexical scope
- Asynchronous JavaScript: `fetch`, `async/await`, error handling
- DOM manipulation: dynamically rendering data as HTML

## ▶️ How to Run
Simply open any `.html` file in a browser. For the array/function exercises, open the browser's **Developer Console** (F12) to see the output — results are logged there, not displayed on the page.
